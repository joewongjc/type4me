# iPhone 1.1.0 发版材料

本页为 GitHub v3.1.0 对应的 iPhone 版 1.1.0 准备文案。GitHub Release 的 v3.1.0 也包含 Mac 版；iPhone 版通过 TestFlight 和 App Store 分发。仓库中的 TestFlight 邀请链接可用于加入测试，但 1.1.0 构建的上传、审核和可用状态需在 App Store Connect 确认。

## TestFlight：测试重点

### 简体中文

感谢测试 Type4Me 1.1.0！请重点体验：

- 左右滑动模式拨盘切换模式；从 Mac 同步多个模式后，检查顺序与可用状态。
- 按住说话时左滑取消、右滑锁定；轻点麦克风锁定录音，并检查标点键、空格键移动光标及撤销/重做。
- 按住删除键上划并松手清空输入框；试试划回取消、撤销和重做。
- 使用智能感知输入，在设置中切换「输入框上下文」，检查普通输入框中的效果以及敏感输入框的保护。
- 选中错词后按住说出正确内容；尝试补充解释、再次纠正、撤销和「记住」热词。
- 将听写结果插入选中文字，再撤销和重做；修改文本模型地址后测试连接并恢复默认地址。

如遇问题，可在「设置 → 诊断记录」复制记录，并通过 GitHub Issues 反馈使用的 iOS 版本、识别服务与复现步骤。分享前请检查并移除敏感信息。

### English

Thank you for testing Type4Me 1.1.0! Please try:

- Swipe or tap the mode dial; sync several modes from your Mac and check their order and availability.
- Hold to talk, swipe left to cancel or right to lock; tap the microphone to lock recording. Try punctuation, moving the cursor on the space bar, undo and redo.
- Hold the delete key and swipe up to clear the field; try sliding back to cancel, undoing and redoing.
- Try Intelli Sense with input-field context enabled and disabled. Check normal fields and the protection for sensitive fields.
- Select a mistaken word and hold to say the correction. Try providing an explanation, correcting again, undoing, and saving an eligible result as a hotword.
- Dictate over selected text, then undo and redo. Change a text model's endpoint, test the connection, and restore its default address.

If something goes wrong, copy the diagnostic log from Settings → Diagnostics and report it in GitHub Issues with your iOS version, speech provider and steps to reproduce. Review and remove sensitive information before sharing.

## App Store：版本更新说明

### 简体中文

- 新的模式拨盘、录音手势和键盘操作，支持上划删除键清空并撤销。
- 可选开启键盘快捷粘贴，点按粘贴刚复制的文字，支持撤销。
- 智能感知来到 iPhone，并可选中错词后用语音纠正。纠正支持说明错因和原意，删除或回车后也能正常退出纠正状态。
- 新增文本输出和模式级格式设置，支持从 Mac 同步；首页整合历史记录，设置页重新整理。
- 改进撤销与重做、文本模型地址设置和语音会话引导。

### English

- A new mode dial, recording gestures and keyboard controls, including swipe-up to clear with undo.
- Enable Quick Paste to insert recently copied text from the keyboard with a tap, with undo support.
- Intelli Sense on iPhone, plus voice correction for selected text. Corrections better understand explanations of the mistake or intended meaning, and correction mode exits properly after deleting or inserting a newline.
- Configure text output and per-mode formatting, sync settings from your Mac, and explore the refreshed home and settings screens.
- Improved undo and redo, model endpoint settings and voice-session guidance.

## 交接

- iOS 工程准备为 1.1.0（构建号 3）；上传前请在 App Store Connect 确认该版本及构建号可用，并核对 App、键盘和控件的版本一致。
- 由有权限的发布者签名、归档并上传 iOS 构建，按渠道完成审核与发布；TestFlight 链接本身不代表 1.1.0 已可安装。
- `updates-ios.json` 的 TestFlight 与 App Store 条目分别在对应版本可用后更新；不要提前提示用户升级。
- 已准备 1.1.0 中文键盘、模式拨盘、选中纠正及录音手势截图；英文键盘截图及中英文首页、设置截图仍为旧布局，需另行补拍。现有截图为 1206 × 2622，App Store 提交前请核对所需设备尺寸。
- GitHub v3.1.0 的 Mac 云端与本地 DMG 由发布者从发布提交构建、签名并上传；实际制品就绪后再更新 Mac 端更新清单。
