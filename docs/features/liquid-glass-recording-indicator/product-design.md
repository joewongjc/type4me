## 1. 背景

当前「常规 / Regular」指示条把录音和处理反馈绘制在整个深色胶囊背景中，用户可选的效果是线条、粒子云、电平、无特效和无。这些效果虽然能表达活动状态，但与录音控制、实时文本和处理文案是彼此分离的视觉语言；在长文本、低对比度屏幕或需要快速扫读时，背景运动也会分散注意力。

本设计以 [LerSent001/orb](https://github.com/LerSent001/orb) 的液态玻璃预设为视觉基础，重构 Regular 指示条：动态内容从背景收束到两个小而明确的前景区域——左侧录音玻璃球和文字内部的滑动光。Orb 源项目包含可导出到 SwiftUI/Metal 的液态玻璃实现及 11 个动态预设（其中 plasma 未采纳，本项目采纳 10 个动态预设并新增 1 个静态红色玻璃预设）；本功能仅采用其所需的预设与着色器算法，并按 MIT 许可证保留归属和许可文本。

## 2. 产品目标

1. **统一视觉语言**：选中的液态玻璃预设同时定义录音球和文字滑光的颜色、流体纹理与高光风格。
2. **取消背景动效**：Regular 指示条不再绘制任何全宽线条、粒子、电平、处理填充或背景进度特效。
3. **清楚表达状态**：录音、实时转写、处理中、恢复中、完成和错误仍应一眼可辨，且不能把循环光效伪装成真实百分比进度。
4. **让实时文本可读**：已确认的转写内容保持稳定；动画只作用于“倾听中”提示或仍在流式变化的文本尾段。
5. **可选择的低干扰体验**：提供真正静态的红色玻璃方案，并遵循系统“减少动态效果”偏好。
6. **不影响既有紧凑型**：Compact 的 24pt 高度、声纹「右入左流、历史固化」语义及全生命周期布局保持不变。

## 3. 非目标

首版不包含：

- 为 Compact 指示条接入 Orb、文字滑光或变更其声纹轨；
- 让用户编辑 Orb 的颜色、速度、折射、形状等底层参数，或内嵌 Orb 编辑器；
- 以视觉动画显示真实的 ASR、LLM 或网络百分比进度；
- 修改录音状态机、ASR 分段、文字注入、快捷键或取消行为；
- 自动追随上游 Orb 仓库的每一次预设变化。

## 4. 总体体验

### 4.1 Regular 指示条构图

```text
录音中

╭──────────────────────────────────────────────────────╮
│  ◉ 液态玻璃球       倾听中 / 实时识别文本           × │
╰──────────────────────────────────────────────────────╯
   结束录音              字内滑动光                  取消

处理中

╭──────────────────────────────────────────────────────╮
│                  正在识别文本                         │
│               ↑ 字形内部的液态滑光                    │
╰──────────────────────────────────────────────────────╯
```

- 胶囊继续使用稳定、低反射的深色磨砂背景、现有尺寸约束和阴影；它不再成为动态画布。
- 左侧 35pt 完成录制控件整体变为液态玻璃球。静止时优先展示材质；鼠标悬停、键盘焦点或按下时才出现清晰的结束录音 affordance，既保持玻璃质感也保证可发现性。
- 文字不会位移、跳动或改变测量宽度。运动仅发生在字形内部的颜色与高光上。
- 右侧取消按钮、`Esc` 取消、Tooltip、悬停文本预览与实时文本开关的现有语义保持不变。

### 4.2 动效原则

1. **前景而非背景**：效果限定在球体和字形掩码内，不能溢出到胶囊背景。
2. **材质在移动，文字不移动**：高光沿文字局部坐标平滑通过，文字基线、宽度、换行和横向截断均不变化。
3. **循环不代表进度**：处理中光效是连续活动反馈，不能从左到右“填满”或显示百分比。
4. **确认内容优先可读**：已确认的文本使用稳定的浅色前景；最新未确认片段才使用流动材质。
5. **静态名副其实**：静态风格不播放球体动画，也不播放文字滑光。

## 5. 录音视觉设置

在“设置 → 外观 → 录音显示”中，将现有“录音动效 / Visual Style”重命名为：

```text
录音视觉 / Recording Visual
选择常规指示条的液态玻璃球与文字光效。
Choose the liquid-glass orb and text glow for the regular indicator.
```

该设置只在“指示条外观”为 Regular 时显示；切换到 Compact 后仍按既有规则隐藏该项、但不清除用户选择。

| 选项（中文） | English | 视觉特征 |

| Siri 波澜 | Siri Ripple | 青、粉、紫的柔和多色流体，默认选项。 |
| 蓝晶液滴 | Blue Crystal Drop | 深蓝与冰蓝折射，高透明水滴感。 |
| 色差液态金属 | Chromatic Liquid Metal | 冷银色金属基底与低调的蓝橙色差高光。 |
| 冰霜流体 | Frost Fluid | 冰白、浅蓝、柔雾化的磨砂玻璃。 |
| 虹彩欧泊 | Iridescent Opal | 奶白基底上的青、粉、紫虹彩。 |
| 声纹薄膜 | Voiceprint Membrane | 深色薄膜上的洋红、珊瑚与紫色振纹。 |
| 紫焰流核 | Violet Flame Core | 紫色流核与明亮边缘火焰感。 |

默认值为 **Siri 波澜 / Siri Ripple**。它是最能传达语音输入感的方案，但不承担录音状态的唯一提示；状态文案、按钮和 VoiceOver 仍是主语义来源。

Orb 上游的 `plasma` 预设未列入首版选项：它不在本次确认的视觉目录中，后续若需要增加，必须补齐中英文命名、preview、测试和产品验收，而不是悄悄改变现有预设列表。

### 5.1 旧选项迁移

线条、粒子云、电平、无特效、无会从设置中移除。旧值在升级时一次性转换为最接近的新体验：

| 旧值 | 升级后 | 理由 |
|---|---|---|
| 线条 | Siri 波澜 | 保留流动的语音联想。 |
| 粒子云 | 声纹薄膜 | 保留更强的细节和能量感。 |
| 电平 | 彩色声场 | 保留音频响应的丰富色彩。 |
| 无特效 | 静态 | 保留低干扰取向。 |
| 无 | 静态 | “无”不再隐藏 Regular 指示条；升级后显示静态红色玻璃球。 |

最后一项是有意的行为变化：用户已要求取消“无”。Release Notes 必须明确说明这一点。

## 6. 状态设计

| 阶段 | 球体 | 文本 | 背景 |
|---|---|---|---|
| Preparing | 选中材质的低能量球体，未读取音量。 | `倾听中 / Listening` 使用缓慢字内滑光。 | 静态深色玻璃。 |
| Recording，无实时文本 | 球体随声音轻微调整流速、边缘亮度与局部轮廓。 | `倾听中 / Listening` 使用字内滑光。 | 静态深色玻璃。 |
| Recording，有实时文本 | 同上。 | 已确认前缀为稳定浅色；最新未确认尾段使用字内滑光。 | 静态深色玻璃。 |
| Processing | 录音按钮与球体退出。 | 整个处理文案使用连续、低干扰的字内滑光。 | 静态深色玻璃。 |
| Recovering | 保留现有红色恢复语义标记。 | 恢复文案使用字内滑光。 | 静态深色玻璃。 |
| Done | 无球体。 | 普通完成反馈文字；最后一次滑光结束后停下。 | 静态深色玻璃。 |
| Error | 无球体。 | 普通高对比错误文字和现有错误图标。 | 保留现有克制的错误色调，不播放动效。 |

### 6.1 声音与滑光的关系

录音中的音量不是“球体大小”或“文字长度”的映射。声音仅在安全范围内提高选中材质的流速、边缘亮度和细微轮廓起伏；安静时仍维持低能量的材质状态。这样既避免机械电平表感，也不会造成可读性或布局抖动。

滑光按照预设本身的液态纹理在字形内平移，并叠加一条柔和高光。它的周期可以随当前音量略微加快，但不以声量改变文字颜色的可读性下限。

### 6.2 静态与减少动态效果

- 选择“静态”时，球体与文字使用固定的红色玻璃材质；它们不响应时间或音量。
- 系统开启“减少动态效果”时，任意动态预设都冻结在对应材质的确定性帧；文字与球体保留玻璃质感但停止时间、音量驱动的变化。
- 这两种情况下，处理中仍通过文案本身和系统状态变化告知工作尚未完成，不能加入替代性的背景动画。

## 7. 文本规则

1. **实时文本关闭或尚无识别文本**：`倾听中 / Listening` 作为滑光承载文本。
2. **实时文本开启且存在未确认段**：确认段合并为稳定前缀；最后的未确认段使用当前预设的滑光。
3. **实时文本开启且全部内容已确认**：文本保持稳定，避免已经定稿的内容持续扰动；录音球仍表示麦克风活动。
4. **文本溢出**：沿用现有 180–400pt 宽度、尾部可见与悬停预览行为；材质变化不得改变文本测量结果。
5. **处理中/恢复中**：整个状态文案可以使用滑光，因为它不是用户需要逐字复制或校对的内容。

## 8. 设置页预览

Appearance Preview Stage 继续复用真实 FloatingBarView，不启动麦克风、ASR、网络或文本注入。为覆盖这次的两个关键阶段，预览增加一个本地的阶段切换：

```text
[ 录音中 ] [ 处理中 ]
```

- “录音中”演示球体、确认文本和流式尾段，以及合成音量驱动。
- “处理中”演示选中预设在处理文案中的滑动光。
- 切换语言、录音视觉、实时文本、取消按钮或 Tooltip 设置时，预览立即更新；不重置用户已保存的偏好。

## 9. 本地化、可访问性与交互

- 所有新增设置标题、说明、预览阶段切换和 11 个选项均提供中英文，并在 `tf_language` 改变时立即刷新。
- Finish 控件继续提供“完成录制 / Finish Recording”的 Accessibility Label、Action 和键盘焦点；其可点击区域不因球体的透明边缘缩小。
- 颜色、材质或动画不是唯一状态信号：状态文案、可操作按钮、完成/错误图标和 VoiceOver 文案保持完整。
- Tooltip 关闭时不应意外删掉 Accessibility Action；它只影响视觉提示。

## 10. 验收场景

1. Regular 设置下，旧的线条、粒子云、电平、无特效、无均不可再选择，且指示条背景始终静止。
2. 11 个新选项均能在录音球、`倾听中`、流式尾段和处理文字中表现出一致的风格；“静态”没有任何时间或音量动画。
3. 实时转写时，确认前缀稳定、最新未确认尾段滑光；文本宽度不因动画变化。
4. 停止录音进入 Processing 或 Recovering 后，状态文案有字内液态滑光，但没有全宽进度填充、粒子或电平。
5. Done/Error 后立即停止动态效果；错误语义与现有图标和高对比文字保持清晰。
6. Compact 在全部阶段仍为既定的 24pt 形态和现有声纹轨，完全不渲染球体或文字滑光。
7. 关闭实时文本、取消按钮、Tooltip，以及切换中英文、减少动态效果后，布局和语义均正确。
8. Appearance Preview 与生产 FloatingBarView 使用同一渲染组件；预览不请求麦克风权限，也不会在离开页面后继续运行计时器。

## 11. 成功标准

- 用户可在不到一次下拉选择内更换 Regular 视觉，不需要理解底层着色器参数。
- 无论选择何种预设，转写文字和状态文案始终清晰可读；动态只增强状态感，不遮蔽信息。
- 旧背景特效组件没有残留在 Regular 的录音、处理或完成路径中。
- 视觉回归不会改变 Compact、ASR 处理时序、文字注入、取消快捷键或无障碍操作。

## 12. 外观主题与自适应调研结论

关于指示条是否根据屏幕底层窗口明暗自动切换黑/白文字的「自适应」模式，团队已完成深度技术调研与真机验证，结论为：**不采用屏幕像素采样方案，保持确定性的「暗色」与「明亮」双主题**。

详见独立设计归档文档：[自适应主题与屏幕明暗采样技术调研与设计文档](adaptive-theme-and-screen-sampling-research.md)。

核心决策逻辑：
1. macOS 系统合成器因隐私与安全隔离，不向普通应用暴露底层第三方窗口像素；
2. 真正实现像素级反差色必须申请 macOS 屏幕录制权限（TCC），这会向用户弹出极具侵入性的录屏权限弹窗，破坏应用的轻量与隐私承诺；
3. Type4Me 坚持零权限、完全尊重隐私的设计原则，采用「暗色（默认，含 0.52 黑色底垫保证深邃对比度）」与「明亮」双主题供用户明确选择。
