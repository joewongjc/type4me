# 腾讯云 ASR（中英大模型 2.0）产品设计

> 文档类型：产品设计
> 文档状态：当前有效（设计完成，待实现）
> 设计日期：2026-10-17
> 最后校验：2026-10-18
> 下游文档：`docs/features/tencent-asr/development-design.md`
> 官方文档：实时语音识别 V2 https://cloud.tencent.com/document/product/1093/131127 ；录音文件识别 https://cloud.tencent.com/document/product/1093/37823 ；引擎与计费 https://cloud.tencent.cn/document/product/1093/35682 、https://cloud.tencent.com/document/product/1093/35686

## 1. 背景

Type4Me 的 ASR Provider 列表里早就有“腾讯云”，但它只有配置结构、没有识别客户端，因此在设置中不可见、不可用。

2026-07-20，腾讯云语音识别在**实时语音识别**和**录音文件识别**两个接口上新增了中英大模型 2.0 引擎 `16k_zh_en_2.0`。官方定位是覆盖普通话、英语和多种方言的混合引擎，计费属于“大模型 2.0”档：

| 接口 | 2.0 后付费单价 | 1.0 后付费单价（最低档） | 每月免费额度 | 2.0 免费并发 / 限频 |
|---|---:|---:|---:|---|
| 实时语音识别（WebSocket） | ¥1.0 / 小时 | ¥4.8 / 小时 | 5 小时 | 50 路并发 |
| 录音文件识别（异步任务） | ¥0.8 / 小时 | ¥2.4 / 小时 | 10 小时 | 提交 20 次 / 秒 |

2.0 引擎的价格只有 1.0 大模型的约 1/4 到 1/3，比火山、百炼等国内主流 Provider 也更便宜，同时官方宣称识别效果更好。这是把腾讯云从占位变成可用 Provider 的好时机。

`16k_zh_en_2.0` 目前**不支持**录音文件识别极速版和一句话识别，所以非实时模式只能使用录音文件识别的异步任务接口（提交任务后轮询结果）。

## 2. 产品目标

### 2.1 核心目标

1. 让“腾讯云”成为可用的 ASR Provider，固定使用中英大模型 2.0 引擎 `16k_zh_en_2.0`；
2. 同时提供**实时流式**和**非实时**两种识别模式，用户可以切换，默认实时流式（与 StepFun、百炼、Gemini 等双模式 Provider 一致）；
3. 实时模式边说边出字，句子确认后不再变化，松手后几乎立即上屏；
4. 非实时模式松手后提交完整录音，结果更便宜；
5. Type4Me 热词映射到腾讯云临时热词表；
6. 测试连接真实校验 SecretId、SecretKey、AppID，以及语音识别服务是否已开通、是否欠费；
7. 腾讯云特有的计费类错误（未开通、资源包用尽、欠费）给出可操作的提示；
8. 中英文界面文案完整。

### 2.2 成功标准

1. 用户在设置中看到“腾讯云”，填入 SecretId、SecretKey、AppID 后测试连接通过；
2. 实时模式下说话即出字，句子结束后文字定稿，长时间说话不重复、不丢字；
3. 切换到非实时模式后，松手提交，结果正确注入；
4. 录音条和历史记录显示 `腾讯云 · 16k_zh_en_2.0`；
5. 热词按官方格式发送且不导致请求失败（2.0 引擎热词效果有限，见第 7 节）；
6. 账号未开通、欠费、资源包用尽时，测试连接和实际使用都显示对应的中英文提示；
7. SecretKey 只存在 macOS Keychain 中。

## 3. 非目标

第一版不包含：

- 引擎选择器（不提供 1.0 大模型、`16k_zh`、方言、多语种等其他引擎；`16k_zh_en_speaker_2.0`、`16k_zh_en_meeting` 也不提供）；
- 国际站（`asr.intl.tencentcloudapi.com`）；
- 录音文件识别极速版、一句话识别；
- 云端热词表 ID（`hotword_id`）、自学习模型、替换词表；
- 说话人分离、情绪识别、口语转书面语等增值功能；
- 脏词过滤、语气词过滤（Type4Me 有自己的后处理）；
- 进入“推荐”分组。

## 4. Provider 定位

### 4.1 名称与分组

- 显示名：中文 `腾讯云`，英文 `Tencent Cloud`（沿用现有枚举名称，不改动）；
- 归入“云端”分组，按字母排序；
- 支持模式切换，列表行在非实时模式下显示“非实时”标签；
- 不进入推荐分组，等真实评测后再决定。

### 4.2 适用场景

适合：

- 中文为主、中英混合的日常听写；
- 带方言口音的普通话；
- 对价格敏感的国内用户；
- 已经有腾讯云账号的用户。

不适合：

- 其他语种为主的输入（2.0 引擎只覆盖中英和方言）；
- 中国大陆以外的网络环境（国际调用会返回 6001 错误）；
- 不想使用 SecretId / SecretKey 这类账号级密钥的用户。

## 5. 核心交互

### 5.1 实时流式模式（默认）

1. 按下快捷键即建立 WebSocket 连接并开始发送音频；
2. 识别结果逐字出现在录音条中；
3. 一句话说完（停顿）后该句定稿，后续只更新当前句；
4. 松开快捷键后通知服务端结束，收到最终结果后上屏。

用户感知：`录音中（边说边出字）→ 完成`。

### 5.2 非实时模式

1. 录音中只缓存音频，录音条显示“录音中…”；
2. 松开快捷键后提交识别任务，等待结果；
3. 结果返回后一次性给出最终文本。

用户感知：`录音中 → 识别中 → 完成`。非实时模式是异步任务，等待时间比实时模式长。实测从松手到出字：短句约 2 秒，30 秒录音约 3 秒，2 分钟录音约 5 秒（开发设计 T-12）。

### 5.3 模式选择说明

在模式切换控件下方，沿用项目通用的模式说明，并在 Provider Note 中补充腾讯云的取舍：实时模式出字快；非实时模式更便宜（¥0.8 vs ¥1.0 / 小时），但要多等几秒。

## 6. 设置设计

### 6.1 凭证字段

| 字段 | 类型 | 默认值 | 必填 | 存储 | 显示条件 |
|---|---|---|---|---|---|
| 识别模式 | Picker | `streaming` | 否 | credentials.json | 总是 |
| SecretId | 文本 | 空 | 是 | credentials.json | 总是 |
| SecretKey | Secure | 空 | 是 | Keychain | 总是 |
| AppID | 文本 | 空 | 是 | credentials.json | 总是 |

说明：

- 字段 key 沿用现有 `TencentASRConfig` 的 `secretId`、`secretKey`、`appId`；腾讯云此前在设置中不可见，没有已保存的旧凭证，因此不需要迁移；
- AppID 只在实时模式中使用，但两个模式共用同一套凭证，切换模式时不必重填，所以始终显示、始终必填；
- 不显示引擎选择器。引擎固定为 `16k_zh_en_2.0`，在详情页说明中注明。

### 6.2 字段提示

| 字段 | 提示（中文） | 提示（英文） |
|---|---|---|
| SecretId | 在“访问管理 → API 密钥管理”中创建，建议使用仅授权语音识别的子账号密钥 | Create one under CAM → API Keys. A sub-account key limited to ASR is recommended. |
| AppID | 在“账号信息”页面查看，为纯数字 | Shown on the Account Info page; digits only. |

### 6.3 详情页说明（Provider Note）

实时模式：

> 使用中英大模型 2.0 引擎（16k_zh_en_2.0），支持普通话、英语及多种方言，边说边出字。后付费 ¥1.0/小时，每月免费 5 小时；后付费需在腾讯云控制台手动开启。

> Uses the Chinese-English large model 2.0 engine (16k_zh_en_2.0), covering Mandarin, English, and many dialects, with live transcription. Pay-as-you-go ¥1.0/hour with 5 free hours per month; pay-as-you-go must be enabled in the Tencent Cloud console.

非实时模式：

> 使用中英大模型 2.0 引擎（16k_zh_en_2.0）。结束录音后提交识别任务，需多等几秒，单次录音最长约 2.5 分钟。后付费 ¥0.8/小时，每月免费 10 小时；后付费需在腾讯云控制台手动开启。

> Uses the Chinese-English large model 2.0 engine (16k_zh_en_2.0). The recording is submitted as a recognition task when you stop, which takes a few extra seconds; recordings up to about 2.5 minutes. Pay-as-you-go ¥0.8/hour with 10 free hours per month; pay-as-you-go must be enabled in the Tencent Cloud console.

## 7. 热词

映射到腾讯云**临时热词表**（实时模式 `hotword_list`，非实时模式 `HotwordList`），两个模式规则相同：

- 格式为 `词|权重`，多个词用逗号分隔；
- 最多 128 个词；每个词须同时满足总长度不超过 30 个字符、其中汉字不超过 10 个。超出任一限制则跳过整个热词，不截断；中英混合热词也按这两个上限校验；
- 官方规定热词**不能包含空格**。含空格的英文短语（如 `Claude Code`）去掉空格后发送（`ClaudeCode`）不合适，因此改为跳过该热词，并在详情页说明中提示“含空格的热词不会发送给腾讯云”；
- 不能包含逗号和 `|`（会破坏格式），含有这些字符的热词同样跳过；
- 权重统一为 10。权重 11（超级热词）可能导致过度替换，100（同音替换）不支持 2.0 引擎，第一版都不使用；
- 两种模式都接受临时热词参数（开发设计 T-10），超出上限的热词服务端不报错、静默忽略（T-4）；
- **效果说明**：2026-10-18 用合成语音实测，2.0 引擎的临时热词在两种模式下都没有带来明显改善（如 “Type4Me” 无论是否设为热词都被识别成 “type4么”，开发设计 T-5）。因此详情页不宣传热词能力，热词照常发送但不承诺效果；需要强热词能力的用户建议使用火山或 Soniox；
- 官方实时语音识别 V2 与录音文件识别文档均注明“单个热词不超过 30 个字符（最多 10 个汉字）”。两种模式共用上述过滤规则，并覆盖中文、英文和中英混合热词的边界测试。

## 8. 输出格式

- 保留标点（由 Type4Me 的全局标点策略统一处理）；
- 数字采用腾讯云默认的智能阿拉伯数字转换；
- 不过滤语气词、不过滤脏词，保持原话，交给 Type4Me 现有后处理；
- 非实时结果中的时间戳前缀（如 `[0:1.640,0:3.920]`）必须去掉，只保留文字。

## 9. 限制

| 项 | 实时模式 | 非实时模式 |
|---|---|---|
| 单次录音 | 官方未规定总时长；服务端按语义自动断句（默认短句策略），并开启 VAD 以支持超过 60 秒的录音。实测 90 秒连续说话无丢字、无重复 | 原始音频不超过 5,242,880 字节（约 163 秒，实测确认）；Type4Me 设为 150 秒 |
| 并发 | 2.0 引擎默认 50 路 | 提交 20 次 / 秒，查询 50 次 / 秒 |
| 计费粒度 | 按秒计费，不足 1 秒按 1 秒 | 同左 |
| 网络 | 仅中国站；海外调用返回 6001 | 同左 |

非实时模式超过 150 秒时在本地拦截，提示“录音超过腾讯云非实时识别的 2 分钟上限，请切换为实时流式”（沿用现有双模式 Provider 的提示，分钟数向下取整）。

## 10. 错误体验

| 场景 | 中文提示 | 英文提示 |
|---|---|---|
| 凭证不完整 | 腾讯云识别配置不完整 | Tencent Cloud ASR configuration is incomplete |
| 签名或密钥错误（4002 / AuthFailure） | 腾讯云 SecretId 或 SecretKey 无效 | Invalid Tencent Cloud SecretId or SecretKey |
| AppID 错误或未开通（4003） | 该 AppID 未开通语音识别服务，请在控制台开通 | ASR is not enabled for this AppID. Enable it in the console. |
| 资源包用尽（4004） | 腾讯云语音识别资源包已用完，请购买资源包或开启后付费 | ASR resource pack exhausted. Buy a pack or enable pay-as-you-go. |
| 欠费（4005） | 腾讯云账号已欠费，请充值后重试 | The Tencent Cloud account is in arrears. Top up and retry. |
| 并发超限（4006） | 腾讯云并发路数已达上限，请稍后再试 | Concurrency limit reached. Try again later. |
| 参数错误（4001 / InvalidParameter） | 显示服务端返回的说明 | Shows the server's message |
| 海外调用（6001） | 当前网络被识别为海外，请关闭海外代理，或在代理设置中为 ASR 绕过代理 | Detected as an overseas call. Disable overseas proxies or bypass the proxy for ASR. |
| 服务端临时错误（5000–5002） | 腾讯云服务暂时不可用，请重试 | Tencent Cloud is temporarily unavailable. Retry. |
| 非实时任务失败 | 显示任务返回的失败原因 | Shows the task's failure reason |
| 非实时任务超时 | 腾讯云识别任务超时，请重试或切换为实时流式 | The Tencent Cloud task timed out. Retry or switch to real-time mode. |
| 网络超时 | 沿用现有提示 | Same |

所有错误都附带腾讯云错误码，方便用户对照官方文档排查。

## 11. 测试连接

- **实时模式**：建立 WebSocket 连接，收到握手成功响应后发送少量静音并等待片刻，没有错误即为成功。能校验签名、AppID、服务开通状态和欠费状态，不会产生明显费用；
- **非实时模式**：提交 1 秒静音的识别任务并等待完成。能校验密钥、服务开通和计费状态；按秒计费，费用可以忽略，且通常落在免费额度内；
- 两种模式都只看结果是否成功，不展示识别内容；
- 切换模式后再测一次，即可确认另一种模式也可用。

## 12. 隐私与安全

- SecretKey 只存 Keychain；SecretId、AppID 与模式存在 `credentials.json`（文件权限 0600）；
- 设置页提示使用**仅授权语音识别的子账号密钥**，降低主账号密钥泄露的风险；
- 音频只在用户选用腾讯云时发送；非实时模式以 Base64 直接上传，不经过 COS 或其他存储；
- 日志不记录 SecretKey、签名、完整请求 URL（含签名参数）、音频与识别文本；
- 遵循现有“绕过代理”设置。

## 13. 验收场景

1. **配置**：填入有效凭证，两种模式分别测试连接成功；
2. **实时基础**：说一段中文，边说边出字，松手后文本正确注入；
3. **实时长录音**：连续说话超过 60 秒，自动断句后文字不重复、不丢失；
4. **实时停顿**：中间多次停顿，已定稿的句子不再变化；
5. **中英混合 / 方言口音**：都能正常识别；
6. **非实时基础**：切换到非实时，录音后提交，结果正确且不带时间戳；
7. **非实时超长**：录制超过 2.5 分钟，本地拦截并提示切换实时；
8. **热词**：添加若干中文、英文单词热词，请求正常完成；含空格、超过 30 个字符或超过 10 个汉字的热词被跳过；记录真实语音下热词是否有改善（合成语音实测无明显改善）；
9. **错误凭证**：错误 SecretKey 和错误 AppID 分别显示对应提示；
10. **计费错误**：（如条件允许）资源包用尽或未开启后付费时，提示可操作；
11. **海外代理**：开启海外代理时显示 6001 提示，开启“ASR 绕过代理”后恢复；
12. **录音条与历史**：显示 `腾讯云 · 16k_zh_en_2.0`；
13. **处理模式**：Direct、快速、Intelli Sense、翻译、自定义 Prompt 模式都正常；
14. **语言切换**：App 语言在中英文之间切换，Provider 名称、说明、字段标签、提示、错误即时切换；
15. **菜单栏**：配置后出现在菜单栏 ASR 快速切换中；切到非实时后带“非实时”标识。

## 14. 发布策略

作为普通云端 Provider 发布，CHANGELOG 中说明“腾讯云现已可用，支持中英大模型 2.0 实时与非实时识别”。发布后观察：

- 实时模式的首字延迟与准确率，与火山、百炼对比；
- 非实时模式的任务等待时间分布；
- 4004 / 4005 / 6001 的出现频率，判断计费与网络提示是否足够清楚；
- 用户对引擎选择的需求（是否需要 1.0 或方言专用引擎）。
