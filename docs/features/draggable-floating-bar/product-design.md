# Type4Me 录音指示器拖动定位产品设计

> 文档类型：产品设计
> 文档状态：当前有效（已实现，待用户验收）
> 设计日期：2026-10-14
> 最后校验：2026-10-14
> 实现基线：`feat/draggable-floating-bar`
> 关联开发设计：[development-design.md](development-design.md)

## 1. 背景

录音指示器（Floating Bar）目前固定显示在鼠标所在屏幕可见区域的底部居中，胶囊底边距可见区域底边 `TF.barBottomOffset`（48pt）。

语音输入最常见的落点恰好是屏幕底部的输入区域：聊天软件输入框、终端命令行、网页评论框、IDE 底部面板。指示器会遮住用户正在输入或正在阅读的那一行。用户反馈原文：

> 建议指示条在预览窗口或者弹出时，可通过鼠标拖动来设置位置，设置以后固定在这个位置。因为很容易遮住一些信息。

本功能让用户直接拖动指示器到合适位置并持久保存，同时保留一键回到默认位置的路径。

## 2. 产品目标

1. 鼠标悬停在录音指示器上时，在胶囊锚定边一侧居中显示拖拽手柄；
2. 按住手柄拖动可移动指示器，松手后位置立即持久保存，后续每次录音都显示在该位置；
3. 拖动过程中，屏幕上显示一条横向与一条纵向虚线参考线，交叉点为当前样式下指示器默认位置的中心点；
4. 拖动时靠近参考线会按轴自动吸附：靠近竖线吸附水平位置，靠近横线吸附垂直位置，同时靠近则吸附到交叉点；
5. 每次进入吸附时触发一次触控板触感反馈（Force Touch 触控板）；
6. 指示器位置以胶囊基准形态的中心点记录；
7. 指示器随内容变高时从锚定边向外生长，不会因为变高而向屏幕外溢出；
8. 设置页提供“恢复默认位置”；
9. 位置对所有显示器通用，在不同尺寸、不同分辨率的屏幕上表现可预期；
10. 所有新增文案中英文完整，切换语言即时生效。

## 3. 非目标

本期不包含：

- 每个显示器分别记忆位置；
- 每种指示器样式（Regular / Compact）分别记忆位置；
- 跟随文本光标或焦点输入框自动避让；
- 键盘方向键微调位置；
- 在设置页外观预览（Appearance Preview）中拖动设置位置；
- 拖动时按 Esc 取消本次拖动；
- 拖动整个胶囊（只有手柄可拖动，胶囊上的按钮和悬停行为保持不变）；
- 自由缩放指示器尺寸。

## 4. 术语

| 术语 | 含义 |
|---|---|
| 胶囊 | 指示器本体，即 Regular 或 Compact 的圆角条 |
| 基准形态 | 当前样式未展开时的胶囊尺寸：Regular 高 55pt；Compact 高 24pt。Compact 实时文本展开（48pt）、悬停预览、提示气泡都不属于基准形态 |
| 位置中心 | 基准形态胶囊的中心点，是本功能唯一记录的位置 |
| 默认中心 | 默认位置下的位置中心：水平为可见区域中线，垂直为“可见区域底边 + 48pt + 基准高度 / 2” |
| 锚定边 | 胶囊变高时保持不动的那条边：位于屏幕下半部分时为底边，上半部分时为顶边 |
| 可见区域 | `NSScreen.visibleFrame`，已扣除菜单栏与 Dock |

## 5. 拖拽手柄

### 5.1 出现与消失

- 鼠标进入胶囊约 150ms 后，手柄淡入；
- 鼠标在胶囊、胶囊与手柄之间的间隙、手柄三者之间移动时，手柄保持显示；
- 鼠标离开上述整体区域约 300ms 后，手柄淡出；离开后在宽限期内回到区域则继续显示；
- 拖动过程中手柄始终显示，松手后按鼠标当前位置决定是否继续显示。

手柄只在指示器能接收鼠标的阶段出现，即 Preparing、Recording、Processing、Recovering、Done、Error 均可出现；Hidden 阶段和手动输入编辑时不出现。

### 5.2 位置与衔接

手柄始终位于**锚定边一侧**，水平居中，与胶囊外壳直接贴合（间距 0pt）：

```text
下半屏（底边锚定）                上半屏（顶边锚定）

   ┌ 提示气泡 / 悬停预览 ┐            [:::  ← 玻璃拉手]
   └────────────────────┘          ┌──────────────┐
   ┌──────────────┐                │    胶囊      │
   │    胶囊      │                └──────────────┘
   └──────────────┘                ┌ 提示气泡 / 悬停预览 ┐
     [:::  ← 玻璃拉手]             └────────────────────┘
```

这样手柄永远不会与向外弹出的提示气泡、悬停转写预览重叠。默认位置下手柄在胶囊正下方，与需求描述一致。

### 5.3 视觉与材质

- **微型一体式拉手**：宽 24pt × 高 10pt，贴边凸起 Tab 形态；
- **圆角过渡**：外侧两角倒圆角 4pt，内侧与胶囊平齐无缝对接（下半屏底边圆角，上半屏顶边圆角）；
- **同款液态玻璃材质**：与胶囊完全相同，复用 `VisualEffectBlur` 磨砂毛玻璃层、对比度底板与折射高光边框，在深浅主题下均与指示器保持一致；
- **抓握点阵纹理**：拉手内部居中绘制 2 行 × 3 列盲文状抓握点阵（6-dot Grip Dots），点径 1.6pt，水平间距 2.8pt，垂直间距 2.0pt；
- **光标**：使用系统标准指针，避免非激活浮窗光标栈冲突；
- **提示气泡**：悬停手柄约 150ms 后，在胶囊外侧弹出与「完成/取消」按钮同组件同材质的磨砂毛玻璃 Tooltip：`拖动以移动指示器 / Drag to move the indicator`。
## 6. 拖动

### 6.1 开始与过程

- 只有在手柄上按下才开始拖动；胶囊上的完成、取消按钮及其现有按住拖动反馈保持原行为；
- 按下手柄后移动超过 3pt 才进入拖动，避免轻点误移；
- 拖动中指示器跟手移动，抓取点与胶囊的相对位置保持不变；
- 拖动中隐藏悬停转写预览、动作提示、模式提示，松手后恢复正常逻辑；
- 录音、识别、注入流程不受拖动影响：拖动不会暂停录音，也不会改变快捷键行为；
- 如果拖动期间会话结束（指示器原本应淡出），指示器变为不含内容的空胶囊，跟随拖动直到松手；松手后保存位置并淡出。如果松手前又开始了新的录音，就直接显示新会话内容，不再淡出。

### 6.2 边界

- 指示器始终被限制在当前屏幕的可见区域内，包括胶囊基准形态和锚定边一侧的手柄；
- 拖到屏幕边缘时贴边停住，不会被拖出屏幕或钻到菜单栏、Dock 下面。

### 6.3 跨屏幕

- 拖动过程中可以把指示器拖到另一块屏幕；参考线跟随位置中心所在的屏幕显示；
- 松手时，以位置中心所在的屏幕为基准计算并保存位置；
- 下次录音仍按现有规则选屏（鼠标所在屏幕），在该屏幕上套用保存的位置。

## 7. 参考线与吸附

### 7.1 参考线与全天候高对比度

拖动开始时，在位置中心所在屏幕上显示两条参考线：

- 竖线：穿过默认中心，上下贯穿可见区域；
- 横线：穿过默认中心，左右贯穿可见区域；
- **双层对比度渲染（Dual-contrast Stroke）**：
  - **未吸附**：底层 2.2pt 暗色底影（`black.opacity(0.35)`）+ 顶层 1.0pt 白色虚线（`[6, 4]`），保证在纯白网页、深色窗口及任意壁纸下均清晰可见；
  - **吸附后**：底层 3.0pt 柔和阴影 + 顶层 1.5pt 实心 **Type4Me 暖琥珀色（`TF.amber`）**，吸附时橙金高光聚焦；
- 参考线不接收鼠标，不遮挡其它应用的操作；
- 松手后参考线淡出。

默认中心随当前指示器样式变化（Regular 与 Compact 的基准高度不同），参考线始终对应当前样式的默认位置。
### 7.2 按轴吸附

| 情况 | 结果 |
|---|---|
| 位置中心与竖线的水平距离进入吸附阈值 | 水平坐标吸到竖线，垂直坐标自由 |
| 位置中心与横线的垂直距离进入吸附阈值 | 垂直坐标吸到横线，水平坐标自由 |
| 两者同时满足 | 吸到交叉点，即回到默认位置 |

按轴吸附覆盖了最常见的诉求：“保持水平居中，只是抬高一点”。

### 7.3 阈值与迟滞

- 进入吸附：距离 ≤ 8pt；
- 脱离吸附：距离 > 14pt；
- 两者之间保持当前状态，避免在边界附近来回跳动。

### 7.4 触感反馈

- 每个轴从“未吸附”变为“已吸附”时触发一次对齐触感；
- 两个轴在同一次移动中同时进入吸附，只触发一次；
- 保持吸附或脱离吸附时不触发；
- 没有 Force Touch 触控板（例如使用鼠标）时没有触感，其余行为不变。

## 8. 位置记录与生长方向

### 8.1 记录什么

只记录位置中心，且每个轴独立：

- 水平：要么“默认”（吸附在竖线上），要么“相对屏幕宽度的比例”；
- 垂直：要么“默认”（吸附在横线上），要么“距下边或上边的距离”。

吸附在某个轴上时，该轴保存为“默认”而不是具体坐标。以后如果调整了默认底边距离，或者用户切换了指示器样式，吸附过的轴会自动跟随新的默认位置。

### 8.2 为什么水平用比例、垂直用距离

- 水平：多数用户希望“偏左一点”“靠右侧”，比例在宽窄不同的屏幕上都保持相同的视觉关系；
- 垂直：用户关心的是“离底部多远才不挡输入框”，这个需求是以点数计的，换到更高的屏幕不应该按比例跑到中间去。垂直距离从较近的那条边（底边或顶边）量起。

### 8.3 生长方向

指示器的胶囊会在基准形态之外变高（Compact 实时文本展开），还会弹出提示气泡、悬停预览：

- 位置中心在可见区域下半部分：底边锚定，胶囊向上长，气泡和预览向上弹出（与现在一致）；
- 位置中心在可见区域上半部分：顶边锚定，胶囊向下长，气泡和预览向下弹出；
- 水平方向始终以位置中心为轴向两侧对称变宽。

胶囊宽度变化（Regular 随实时文本变宽）只影响水平方向。如果变宽后会超出屏幕，就整体向内平移，保持完全可见；位置中心本身不被改写。

### 8.4 跨屏与屏幕变化

- 保存的位置在任何屏幕上都先换算成具体坐标，再限制在可见区域内；
- 显示器分辨率改变、Dock 显示或隐藏、接入或拔出显示器后，下次显示指示器时自动重新换算；正在显示的指示器也会立即修正，不会停留在屏幕外。

## 9. 关联浮窗

以下浮窗当前与指示器共享“底部居中”位置，需要随之更新：

| 浮窗 | 行为 |
|---|---|
| 手动输入窗（Manual Input） | 出现在指示器所在位置：水平以位置中心对齐，垂直沿同一锚定边生长 |
| 纠错学习卡片（Correction Learning） | 显示在指示器外侧：底边锚定时在指示器上方，顶边锚定时在指示器下方 |

Ask Anything 选区面板（Selection Ask）有独立定位逻辑，不受影响。

## 10. 设置

在 `外观 → 录音显示` 分组末尾新增一行：

| 元素 | 中文 | English |
|---|---|---|
| 标题 | 指示器位置 | Indicator Position |
| 说明 | 将鼠标悬停在录音指示器上，拖动旁边的手柄即可移动。 | Hover over the recording indicator and drag its handle to move it. |
| 状态（默认） | 默认 | Default |
| 状态（自定义） | 自定义 | Custom |
| 按钮 | 恢复默认 | Reset to Default |

- 位置为默认时按钮置灰；
- 点击后立即生效：如果指示器正在显示，平滑移动回默认位置；
- 这是非破坏性操作，不需要二次确认。

外观预览（Appearance Preview）不显示手柄，也不反映自定义位置；预览只负责展示指示器外观。

## 12. 可访问性

- 手柄提供无障碍元素与标签；
- 拖动本身依赖指针设备，无障碍用户通过设置页的“恢复默认”保证可以回到可预期的位置；
- 开启“减少动态效果”时，手柄淡入淡出、恢复默认时的移动动画改为直接切换；
- 开启“降低透明度”时，参考线使用不透明颜色。

## 13. 兼容性

| 场景 | 行为 |
|---|---|
| 升级后首次启动 | 无保存位置，显示在默认位置，与升级前一致 |
| 保存的数据损坏或无法解析 | 视为默认位置，不报错 |
| 切换 Regular / Compact | 共用同一个位置中心；吸附在默认上的轴跟随新样式的默认位置 |
| 切换浅色 / 深色浮条主题 | 手柄与参考线随主题变色 |
| 全屏应用中录音 | 与现有指示器一致，参考线同样出现在全屏空间 |
| 多个 Space | 与现有指示器一致 |

## 14. 验收场景

1. 默认安装，录音时指示器位置与升级前完全一致；
2. 悬停胶囊约 150ms 后，正下方出现手柄；移到手柄上，手柄不消失；移开约 300ms 后消失；
3. 拖动手柄时出现十字虚线，交叉点与默认位置的胶囊中心重合；
4. 将指示器向上拖 150pt，左右保持在竖线附近：水平吸附到中线、竖线高亮、触控板震动一次；松手后，下次录音指示器出现在同一高度、水平居中；
5. 拖离再拖回交叉点附近：两条线高亮，指示器吸回默认位置，触控板只震动一次；设置页显示“默认”；
6. 在 8pt 到 14pt 之间来回晃动，不会反复吸附，也不会反复震动；
7. 把指示器拖到屏幕上半部分：手柄出现在胶囊上方；Compact 开启实时文本时向下展开；悬停预览、提示气泡向下弹出；
8. 把指示器拖到屏幕边角：始终完整可见，手柄不进入菜单栏或 Dock 区域；
9. 在 14 寸笔记本上设置“底部上方 150pt、偏右 30%”，切换到 27 寸外接屏录音：同样距底部 150pt，水平位于屏幕 30% 处；
10. 录音中拖动：录音不中断，最终文本正常注入；
11. 拖动中会话结束：指示器变为空胶囊，仍可继续拖动，松手后才淡出，位置已保存；拖动中再次开始录音，松手后指示器不会消失；
12. Compact 开启实时文本，从下半屏拖到屏幕最顶部：展开后的胶囊完整可见，松手后手柄移到胶囊上方；
13. 拖到外接屏后，在不松手的情况下继续说话让胶囊变宽：指示器留在外接屏，不跳回原屏幕；
14. 设置页点击“恢复默认”：正在显示的指示器回到默认位置，按钮置灰；
15. 切换中英文：设置项、手柄 Tooltip 与无障碍标签即时切换；
16. 使用鼠标（无 Force Touch）：吸附与参考线正常，无触感；
17. 手动输入窗与纠错学习卡片跟随自定义位置出现在正确一侧。

## 15. 产品决策汇总

| 决策 | 结论 |
|---|---|
| 拖动方式 | 悬停显示手柄，只有手柄可拖动 |
| 手柄形态 | 宽 24 × 高 10pt 一体式毛玻璃凸起拉手（带 6 点抓握点阵），零悬空间隙 |
| 手柄位置 | 锚定边一侧居中；默认位置时位于胶囊下方 |
| 参考线 | 横竖双层高对比度线（未吸附：暗影+白虚线；吸附：暗影+琥珀金实线） |
| 触感 | 每次进入吸附触发一次 `.alignment` 触感 |
| 记录内容 | 基准形态胶囊的中心点；吸附的轴保存为“默认” |
| 坐标系 | 水平为比例，垂直为距较近边的点数 |
| 生长方向 | 下半屏底边锚定，上半屏顶边锚定 |
| 作用范围 | 全局一个位置，所有屏幕、所有样式共用 |
| 恢复入口 | 拖回交叉点，或在设置页点击“恢复默认” |
| 外观预览 | 不显示手柄，不反映自定义位置 |
| 拖动中会话结束 | 显示无内容的空胶囊，跟随拖动直到松手，再保存位置并淡出 |
