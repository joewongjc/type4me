# Type4Me 录音外观增强配置产品设计

> 分支：`feat/appearance-settings-enhancements`
> 文档类型：产品设计
> 文档状态：已完成
> 设计日期：2026-08-25
> 目标版本：Type4Me 2.x
> 对应开发设计：`docs/features/appearance-settings-enhancements/development-design.md`

---

## 1. 背景

在上一版本中，Type4Me 引入了“指示条外观”维度（“常规 / Regular”与“紧凑型 / Compact”），并确立了 Compact 的全生命周期状态流转。

当前版本在用户体验上仍有进一步定制化的诉求：
1. **气泡提示定制**：部分用户希望完全无干扰的录音体验，不需要在录音开始时出现模式提示气泡或鼠标悬停在按钮上时弹出操作 Tooltips；
2. **操作按钮定制**：部分熟悉全局快捷键（如 `Esc` 键取消）的用户希望精简录音界面，隐藏指示条右侧的“取消”按钮，使视觉更加清爽；
3. **设置项交互优化**：当前选择“紧凑型”时，常规专属配置项（录音动效、实时展示文本、悬停文字预览）以置灰方式展示，占用了界面空间并增加了视觉认知负担。按规范，应在切换为紧凑型时直接隐藏不生效的专属配置项，仅保留通用的外观配置。

---

## 2. 产品目标

1. **新增通用配置项：显示 Tooltips（Show Tooltips）**：
   - 默认开启（`true`）；
   - 开启时：录音开始时居中展示模式提示气泡（如“快速模式”），鼠标悬停在按钮上时展示操作气泡（如“完成录制”、“取消录制 esc”）；
   - 关闭时：不展示模式提示气泡，鼠标悬停在按钮上时不展示任何 Tooltip 气泡。
2. **新增通用配置项：显示取消按钮（Show Cancel Button）**：
   - 默认开启（`true`）；
   - 开启时：录音指示条右侧正常展示取消按钮（Cancel）；
   - 关闭时：录音指示条右侧隐藏取消按钮，但用户依然可以通过键盘 `Esc` 键取消录音。
3. **设置页动态条件展示（Conditional Visibility）**：
   - 切换为“紧凑型”时，直接平滑隐藏常规专属配置项（“录音动效”、“实时展示文本”、“悬停文字预览”），不再显示置灰占位；
   - 通用配置项（“显示 Tooltips”、“显示取消按钮”）在“常规”和“紧凑型”两种模式下均始终可见并生效。
4. **全模式布局优雅适配**：
   - **常规模式隐藏取消按钮**：右侧取消按钮隐藏后，文本区域向右扩展并保留标准内边距，胶囊最小宽度仍保持 180pt（`barWidthCompact`）；
   - **紧凑模式隐藏取消按钮**：紧凑胶囊宽度保持 180pt 不变，右侧保留等宽内边距，中间动态声纹轨道向右平滑延展填充可用区域。
5. **实时预览与多语言一致性**：
   - 设置页顶部的 Appearance Preview 实时响应新配置项的变更；
   - 所有新增文案提供中英文双语支持并支持实时语言切换。

---

## 3. 非目标

第一版不包含：
- 用户自定义取消按钮或完成按钮的尺寸、位置与图标；
- 为除 `Esc` 之外定义其他隐藏取消按钮时的按键映射；
- 改变 ASR 识别流程、录音状态机或后处理反馈逻辑；
- 改变设置卡片中“文本输出”卡片的配置。

## 4. 设置页设计

### 4.1 卡片结构与排序

在 Settings → Appearance → “录音显示 / Recording Display”卡片中，配置项按以下顺序组织：

```text
┌────────────────────────────────────────────────────────┐
│ 录音显示                                                │
│                                                        │
│ 指示条外观 / Indicator Style          [ 常规 / 紧凑型 ▾ ] │
│ ────────────────────────────────────────────────────── │
│ [仅常规可见] 录音动效 / Visual Style   [ 线条 / 粒子云 ▾ ] │
│ ────────────────────────────────────────────────────── │
│ [仅常规可见] 实时展示文本 / Live Transcript        [ 开关 ] │
│ ────────────────────────────────────────────────────── │
│ [仅常规可见] 悬停文字预览 / Hover Text Preview     [ 开关 ] │
│ ────────────────────────────────────────────────────── │
│ 显示 Tooltips / Show Tooltips                    [ 开关 ] │
│ ────────────────────────────────────────────────────── │
│ 显示取消按钮 / Show Cancel Button                 [ 开关 ] │
└────────────────────────────────────────────────────────┘
```

### 4.2 常规模式下的设置页展示

当“指示条外观”为 **常规（Regular）** 时，展示全部 6 项配置：
1. **指示条外观**：下拉选择（常规 / 紧凑型）；
2. **录音动效**：下拉选择（线条 / 粒子云 / 电平 / 无特效 / 无）；
3. **实时展示文本**：Toggle 开关；
4. **悬停文字预览**：Toggle 开关；
5. **显示 Tooltips**：Toggle 开关，副标题：`开启后在录音开始与悬停按钮时显示提示气泡 / Show hints on recording start and button hover`；
6. **显示取消按钮**：Toggle 开关，副标题：`关闭后隐藏取消按钮，仍可通过 Esc 键取消录制 / Hide cancel button; you can still cancel using Esc key`。

### 4.3 紧凑型模式下的设置页展示

当“指示条外观”为 **紧凑型（Compact）** 时，常规专属的 3 项配置（录音动效、实时展示文本、悬停文字预览）自动收起隐藏，界面仅展示 3 项通用配置：
1. **指示条外观**：下拉选择（常规 / 紧凑型）；
2. **显示 Tooltips**：Toggle 开关；
3. **显示取消按钮**：Toggle 开关。

切换模式时，列表项通过标准动画平滑展开或收起，避免界面跳动。

## 5. 交互与布局行为细则

### 5.1 「显示 Tooltips」行为细则

| 场景 | 显示 Tooltips = 开启 (默认) | 显示 Tooltips = 关闭 |
|---|---|---|
| **录音开始 (Preparing / Recording)** | 胶囊正上方居中展示当前模式提示（如 `快速模式`），2 秒后淡出 | 不展示模式提示气泡 |
| **悬停完成按钮 (Hover Finish)** | 按钮正上方展示 `完成录制` 提示气泡 | 不展示任何气泡 |
| **悬停取消按钮 (Hover Cancel)** | 按钮正上方展示 `取消录制 esc` 提示气泡 | 不展示任何气泡 |
| **悬停文本预览 (Hover Transcript)** | 由 `tf_hoverTranscriptPreview` 独立控制 | 由 `tf_hoverTranscriptPreview` 独立控制 |

> **说明**：`显示 Tooltips` 仅控制模式名称提示气泡与按钮操作提示气泡，不影响常规模式下针对长文本的 Transcript Popup 悬停浮层（后者由独立的“悬停文字预览”配置控制）。

### 5.2 「显示取消按钮」行为细则

#### 5.2.1 紧凑模式（Compact）
- **开启时 (默认)**：
  - 胶囊尺寸：`180 × 24 pt`；
  - 布局：`[左: 15×15 完成按钮 (32pt cell)] + [中: 动态声纹轨 (~116pt)] + [右: 15×15 取消按钮 (32pt cell)]`；
- **关闭时**：
  - 胶囊尺寸：**维持 `180 × 24 pt` 不变**；
  - 布局：`[左: 15×15 完成按钮 (32pt cell)] + [中右: 动态声纹轨 (~138pt) 延伸至右侧标准边距 (10pt)]`；
  - 声纹采样与匀速滚动机制保持一致，右侧腾出的空间自然用于显示更长的历史声纹流。

#### 5.2.2 常规模式（Regular）
- **开启时 (默认)**：
  - 布局：`[左: 35pt 完成按钮] + [中: 文本/动效] + [右: 35pt 取消按钮]`；
  - 胶囊宽度：根据文本长度动态计算（`180pt ~ 400pt`）；
- **关闭时**：
  - 布局：`[左: 35pt 完成按钮] + [中右: 文本/动效延伸至右边距]`，右侧使用 10pt 内边距；
  - 胶囊宽度：最小宽度仍为 `180pt`（`barWidthCompact`），长文本时最大仍为 `400pt`；
  - 用户按键盘 `Esc` 键依然能够随时取消当前录制。

## 6. 数据存储与升级兼容性

### 6.1 持久化存储 Key

| 配置项 | 存储 Key | 类型 | 默认值 |
|---|---|---|---|
| 显示 Tooltips | `tf_showTooltips` | `Bool` | `true` |
| 显示取消按钮 | `tf_showCancelButton` | `Bool` | `true` |

### 6.2 兼容性策略
- **老用户升级**：缺少 `tf_showTooltips` 或 `tf_showCancelButton` 时，安全回退到默认值 `true`，体验与升级前完全一致。
- **模式切换状态保持**：在紧凑模式下被隐藏的常规配置项（`tf_visualStyle`、`tf_showLiveTranscript`、`tf_hoverTranscriptPreview`）其已保存值**完全保留**，切回常规模式后立即恢复并生效。

## 7. 本地化与可访问性

### 7.1 中英文文案对照

| 语义 | 中文 (zh) | 英文 (en) |
|---|---|---|
| 显示 Tooltips 标题 | 显示 Tooltips | Show Tooltips |
| 显示 Tooltips 副标题 | 开启后在录音开始与悬停按钮时显示提示气泡 | Show hints on recording start and button hover |
| 显示取消按钮 标题 | 显示取消按钮 | Show Cancel Button |
| 显示取消按钮 副标题 | 关闭后隐藏取消按钮，仍可通过 Esc 键取消录制 | Hide cancel button; you can still cancel using Esc key |

### 7.2 可访问性（Accessibility）
- 隐藏取消按钮时，VoiceOver / Accessibility 树中同步移除 Cancel 按钮元素，避免产生不可见的幽灵可点击项；
- 完成按钮的 Accessibility Label、Action 及快捷键操作保持不变。

## 8. 验收场景

1. **默认值检查**：全新安装或升级后，`显示 Tooltips` 与 `显示取消按钮` 均默认为开。
2. **设置项动态显隐**：
   - 处于“常规”模式时，设置页显示 6 项配置；
   - 切换为“紧凑型”模式时，录音动效、实时展示文本、悬停文字预览平滑隐藏，仅展示指示条外观、显示 Tooltips、显示取消按钮；
   - 切回“常规”模式时，3 项专属配置平滑重新展示，且原有勾选与选择值未被篡改。
3. **Tooltips 控制验收**：
   - 关闭 `显示 Tooltips`：开始录音时不出现“快速模式”气泡，鼠标悬停在 Finish / Cancel 按钮上时不出现气泡；
   - 开启 `显示 Tooltips`：录音开始正常弹出模式气泡，悬停按钮正常弹出操作气泡。
4. **取消按钮控制验收**：
   - 关闭 `显示取消按钮`（常规模式）：右侧取消按钮消失，文本正常填充至右侧，短文本宽度为 180pt，按键盘 `Esc` 录音成功取消；
   - 关闭 `显示取消按钮`（紧凑模式）：右侧取消按钮消失，紧凑条宽度保持 180pt，声纹轨道向右扩展，按键盘 `Esc` 录音成功取消；
   - 开启 `显示取消按钮`：常规与紧凑条均正常呈现右侧取消按钮。
5. **实时预览联动**：在设置页调整任何开关，上方 Preview Stage 能够即时、真实地反映对应视觉与交互变化。
