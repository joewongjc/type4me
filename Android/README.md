# Type4Me Android

安卓上的 Type4Me 语音键盘：在输入框切到 Type4Me 键盘，按住麦克风说话，松手把文字输入到光标处。支持边说边出字、智能感知、润色、翻译、代办、选中纠正、热词、片段替换和历史记录。

参考 `../iOS` 的交互，按安卓的输入法模型重写。App 界面与 iOS 版一致：首页和设置两个底部标签，设置按「识别与处理 / 我的模式 / 词汇 / 文本输出 / 键盘 / 隐私」分组，每项进入独立页面。

## 和 iOS 版对照

| | iOS | Android |
|---|---|---|
| 录音位置 | 主 App 后台录音，键盘扩展通过 App Group 发指令 | 输入法进程直接录音，不需要主 App 待命 |
| 识别 | 18 家云端服务，可选择流式或批量，可保存多套 | 18 家，流式 / 批量可选，可保存多套；另支持自定义 HTTP 批量接口 |
| 文本模型 | 13 家，含 Claude 的 Messages API，可保存多套 | 13 家，含 Claude、Gemini、OpenRouter 等；可保存多套 |
| 键盘 | SwiftUI，模式拨盘、撤销 / 重做、剪贴板建议、标点长按 | 视图体系，模式胶囊与上下排序、撤销 / 重做、剪贴板建议、标点长按 |
| App 界面 | 首页 / 设置两个底部标签，点阵背景和分组卡片 | 同样的底部标签与分组卡片，首页带统计、搜索和按天历史 |
| 处理 | 智能感知、快速、润色、翻译、代办、自定义模式；可按模式调 Prompt、标点 | 同样的模式和设置；智能感知使用精简提示词，翻译支持 18 种目标语言 |
| 词汇与历史 | App Group 共享，Mac 可同步 | 本机维护；可从 Mac 同步并与手机本地词汇合并 |
| 从 Mac 同步 | 可勾选多套服务、模式、词汇和文本输出，并指定默认 | 同样可勾选多套服务、模式、词汇和文本输出，并指定默认 |

安卓不需要「先打开 App 开启会话」这一步：键盘可见时就有麦克风权限，录完即走。

## 需要准备

- 一台 Android 8.0（API 26）或更新设备。
- 本机打包：JDK 17、Android SDK Platform 35、Build-Tools 35。装 Android Studio 最省事，也可以只装 command line tools。
- 只用 CI 打包：不需要本地 SDK，把代码推上 GitHub 即可。
- 一个语音识别服务的凭据：火山引擎、Soniox、OpenAI、Groq、Mistral、Deepgram、Gemini、腾讯云等 18 家中的任意一家，或一个自定义 HTTP 批量接口。
- 润色、翻译、智能感知和代办需要一个文本模型：任意兼容 OpenAI `/chat/completions` 的服务，或 Claude 的 Messages API。
- 可选：相机权限，用于扫描 Mac 上的同步二维码。

## 打包

```bash
cd Android
./gradlew assembleDebug
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`，安装：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

没有 `adb` 时，把 APK 传到手机上点开安装，允许「安装未知来源应用」即可。

### 用 GitHub Actions 打包

`.github/workflows/android.yml` 会在 `Android/` 有改动时运行单元测试并构建 debug APK。打开 Actions 里对应的一次运行，下载 `type4me-android-debug` 工件，解压得到 APK。

## 启用键盘

1. 打开 Type4Me，点「打开输入法设置」。
2. 在「屏幕键盘 / 管理键盘」里打开 Type4Me。
3. 在任意输入框点键盘切换键（🌐），选择 Type4Me。
4. 回到 Type4Me 点「授权麦克风」。

## 配置

### 识别服务

| 服务商 | 需要的字段 | 识别方式 |
|---|---|---|
| 火山引擎 | API Key（新版控制台），或 App ID + Access Token（旧版）；流式模型 2.0 或大模型 | WebSocket 流式，边说边出字 |
| Soniox | API Key；断句灵敏度 | WebSocket 流式，边说边出字 |
| OpenAI | Base URL、模型、API Key | 整段上传 |
| Groq | Base URL、模型、API Key | 整段上传 |
| Mistral AI | Base URL、模型、API Key | 整段上传 |
| SiliconFlow | Base URL、模型、API Key | 整段上传 |
| 自定义 | 任意 OpenAI 兼容的 Base URL、模型、Key | 整段上传 |

「测试」按钮会真实连接一次：流式服务会发约 0.2 秒静音并等待服务器的鉴权/额度结果，批量服务会上传约 1 秒静音。会计入服务商用量。

自定义地址支持 `https://`，也允许局域网内的 `http://` 服务（应用清单允许明文流量）。

### 处理模型

兼容 OpenAI `/chat/completions` 的服务。内置 DeepSeek、Moonshot、通义百炼、火山方舟、OpenAI 预设，也可以选「自定义」。

### 模式

设置页「我的模式」点一行即可设为键盘默认模式，点右上角「管理」勾选键盘上显示哪些模式：

- **智能感知**：读取光标前后的有限上下文，按输入框场景整理。密码框和疑似凭据的上下文不会发给模型。
- **快速**：识别原文直接上屏。
- **润色**：按 Mac 版「语音润色」的完整提示词整理。
- **翻译**：翻译成所选目标语言（英语、简体中文、日语、韩语）。
- **代办**：按 Mac 版「代办」的完整提示词直接交付成品。

处理失败时自动回退识别原文，并在键盘上提示。

### 词汇

设置页「词汇」分两个页面：

- **热词**：输入一个词后点加号。热词会作为识别提示发给火山引擎、Soniox，以及支持 prompt 参数的批量服务。
- **片段替换**：点「添加片段替换」分别填写触发词和替换内容。它在模式处理之前改写识别原文，触发词忽略大小写和空格。

### 文本输出

- **盘古之白**：在中文和英文、数字之间加空格，或保持原样、去掉这些空格。
- **去句末标点**：保留、只去掉句号，或去掉句末标点。

### 从 Mac 扫码同步

Mac 版 Type4Me 的侧边栏「手机版」会把配置生成二维码。在设置页点「从 Mac 扫码同步」，对准二维码即可导入：

- 识别服务：火山引擎、Soniox，以及 OpenAI、Groq、Mistral、SiliconFlow、自定义等 OpenAI 兼容服务。
- 文本模型：DeepSeek、Moonshot、百炼、火山方舟、OpenAI，或任意带 Base URL 的兼容服务（Claude 等非兼容接口会跳过）。
- 键盘上启用的模式、翻译目标语言、热词和片段替换。

和 iOS 使用同一个 `T4M2.` 载荷（zlib 压缩的 JSON）。配置较大时 Mac 会拆成多张码轮播，扫到的进度会显示在底部，扫齐后自动导入。密钥写入这台手机的 Android 密钥库；标记为密钥的额外字段不会再显示在明文输入框里。

可以导入多套识别服务和文本模型，并在导入页指定默认；每套服务各自保存自己的凭据。Mac 上无法映射到当前客户端的服务会在结果里列出。

### 首页与历史记录

首页显示今日和累计字数、说过次数和约节省时间。最近 200 条按天分组，可以按模式筛选、搜索原话或结果；点一条展开原文和删除按钮，右侧按钮复制。历史只存在这台手机上，以明文保存在应用私有目录；清空需要二次确认。

## 使用

1. 按住麦克风说话，松手出字。流式服务会边说边显示识别文字。
2. 录音时左滑取消，轻点麦克风锁定；锁定时再点一次结束。
3. 选中输入框里的文字后，键盘会提示「纠正」，按住麦克风说出正确内容。配置了文本模型时会结合上下文推断正确写法；没有模型时使用识别原文替换。
4. 输入框在处理过程中被关闭或切换到别的应用时，文字会改投剪贴板，不会插进新输入框。
5. 密码输入框不提供语音输入。

## 当前范围

已经做了：

**键盘**

- 模式胶囊、按住说话、左滑取消、轻点锁定、计时、录音电平光晕、实时部分文字。
- 撤销 / 重做：听写、纠正、清空整框都能撤回和重做；删除键上划清空输入框。
- 空格键左右拖动移动光标；标点键上滑输入句号、长按选择更多标点、切换中英文标点；按键音与震动可分别关闭；收起键盘键。
- 键盘顶部的剪贴板快捷粘贴建议。
- 未配置处理模型时，需要模型的模式在键盘上置灰；模式可在「我的模式」里上下排序。

**识别与处理**

- 18 家云端服务都已接入：火山引擎、Soniox、OpenAI、Groq、Mistral、阶跃星辰、MiMo、Deepgram、Cartesia、AssemblyAI、ElevenLabs、Gemini、Grok、Meta Muse、百炼、Azure、腾讯云和自定义 HTTP 批量接口；另有 SiliconFlow 和 OpenAI 兼容自定义预设。
- 支持流式 / 批量切换的服务可在设置里选择识别方式；可保存多套识别服务并随时切换。
- 13 家文本模型：火山方舟、DeepSeek、百炼、Kimi、智谱、MiMo、MiniMax 国内 / 海外、OpenRouter、OpenAI、Gemini、Claude 和自定义；含 Claude Messages API、思考开关和推理强度参数；可保存多套并切换。
- 智能感知、快速、润色、翻译、代办和自定义模式；自定义模式可新建、编辑 Prompt、改名、删除、排序。
- 每个模式可单独设置标点、短文本跳过和翻译目标；翻译支持 18 种目标语言，并对结果做轻量文字系统校验，必要时重试。同文字系统的误译（例如英语译成西班牙语）无法可靠判断。
- 选中纠正支持多处同错一并替换、结果不对时按住再说一次、记住热词和撤销。
- 热词、片段替换、历史记录、文本输出（盘古之白、去句末标点、用『』代替‘’）。

**从 Mac 同步**

- 扫码后先预览并勾选要导入的服务、模型、模式、词汇和文本输出，并指定默认服务。
- 可导入多套识别服务和文本模型、自定义模式和模式参数（标点、短文本跳过、翻译目标）；热词和片段与手机本地合并。
- 系统相机扫 Mac 二维码可直接打开导入页（`type4me://`）。

**App**

- 首页统计、按天历史、搜索、模式筛选；历史显示「已复制到剪贴板」和处理失败说明，并支持按条删除。
- 首次使用引导、第三方 AI 服务授权、诊断记录页、App 内语言切换。
- 麦克风被通话或其他 App 占用时给出具体原因。
- 快捷设置磁贴打开 Type4Me；启动器长按快捷方式（输入法设置、App 设置）。
- Android 13+ 支持系统级单应用语言。

还没做：

- 模式拨盘的视觉交互（当前是胶囊加「我的模式」里的上下排序）。
- 应用图标选择。
- 自动版本更新提示。
- 智能感知仍使用精简提示词和轻量校验，尚未完整移植 Mac 的提示词与输出校验器。
- 部分服务商的账号字段需要在「额外参数」里按 `key=value` 填写（例如 Azure 的 resource/deployment、腾讯云的 secretId/secretKey/appId、自定义 HTTP 的 headers/bodyTemplate/resultPath）；真实服务的鉴权、额度和音频格式仍需真机验证。
- 阶跃星辰的批量识别尚未接入；其余已接入服务的批量能力以设置里的选项为准。

两端都还没有：

- 本地离线识别（SenseVoice / sherpa-onnx）。
- 智能感知的表达习惯学习（iOS 键盘也读不到其他 App 的编辑行为）。

iOS 的后台会话、闲置超时和画中画保活，是因为 iOS 键盘不能直接录音；安卓输入法可以自己录音，不需要这些绕行方案。

## 开发

```bash
cd Android
./gradlew testDebugUnitTest      # JVM 单元测试，不需要设备
./gradlew assembleDebug          # 打包
```

单元测试覆盖 WAV 封装、文本输出、模式 / 提示词、纠正、片段替换、智能感知守卫、扫码载荷、配置校验，以及 18 家识别服务的协议解析和签名；流式会话用本地 WebSocket / MockWebServer 验证连接、发送、部分结果和结束。目前 194 个测试全部通过。真实服务商的鉴权、额度和音频格式仍需要真机验证；模拟器可以装 APK 和看设置页，但模拟器麦克风延迟高，不适合判断实际体验。
